# Client handover — template

Use this after a client says yes (€500 flat). Copy it per client, fill the
placeholders, and send it with the final files. Two hosting options — offer
both; Option A is recurring revenue, Option B costs them nothing monthly.

---

## What you receive

- Your complete website: a self-contained folder (`index.html` + images).
  No frameworks, no build tools, no database — it works on any host, forever.
- Full ownership: the files are yours, no lock-in to us.
- One round of revisions is included in the €500.

## Option A — We host & maintain it (recommended)

**€15/month** *(adjust)* — we handle everything:

- Hosting, HTTPS, and your domain connected
- Small content edits (hours, prices, photos) within 2 business days — just
  email us
- Uptime and backups

You do nothing. Cancel anytime — we hand you the files and the DNS settings.

## Option B — Self-host for free (we set you up, ~30 min)

Your site can run free forever on GitHub Pages + Cloudflare:

1. **Create a GitHub account** at github.com (free).
2. **Create a repository** named `<yourname>.github.io`, upload the website
   folder we gave you (drag-and-drop on github.com works).
3. **Enable Pages:** repo → Settings → Pages → Source: `main` branch, `/ (root)`.
   Your site is now live at `https://<yourname>.github.io`.
4. **Your own domain (optional):** buy the domain at Cloudflare (at-cost pricing),
   then in the repo add a file named `CNAME` containing your domain, and in
   Cloudflare DNS add a `CNAME` record pointing your domain to
   `<yourname>.github.io`. HTTPS is automatic.
5. **Editing later:** replace files in the repo — the site updates in ~1 minute.

We'll do this setup **with you on a call** as part of the €500, or entirely
**for you** for a one-time €50 *(adjust)*.
